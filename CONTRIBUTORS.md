## Becoming a contributor

When your pull request is merged, add your name and GitHub handle to this list.

We welcome contributions in these areas:
- Heuristics that score risk in release diffs
- Registry adapters for PyPI and crates.io
- Sandboxed archive extraction and security hardening
- Test fixtures modeling real supply-chain attack patterns
